# 1. Presentación del proyecto

## 1.1. Nombre de la aplicación

El nombre de nuestro sistema es **Synkra**, tanto para la aplicación móvil como para el programa de escritorio.

## 1.2. Descripción general

Synkra es una aplicación destinada a digitalizar y simplificar el proceso de solicitud y gestión de los días moscosos del profesorado.

El profesorado podrá consultar los días disponibles, realizar solicitudes y comprobar el estado de las mismas. Por su parte, el equipo directivo podrá revisar las solicitudes recibidas y aprobarlas o rechazarlas. Además, el personal gestor podrá importar los calendarios escolares necesarios para el funcionamiento de la aplicación.

La solución contempla una aplicación web y móvil para el profesorado, así como un programa de escritorio desarrollado en .NET para la gestión por parte del equipo directivo.

## 1.3. Objetivo principal

El objetivo principal de Synkra es centralizar el proceso de solicitud y gestión de los días moscosos en una única solución, reduciendo el trabajo manual y facilitando la comunicación entre el profesorado y el equipo directivo.

## 1.4. Destinatarios

La aplicación está dirigida a los siguientes perfiles:

| Perfil | Relación con el proyecto |
|--------|--------------------------|
| Profesorado | Utiliza la aplicación para consultar información, solicitar días moscosos y conocer el estado de sus solicitudes |
| Director o equipo directivo | Revista las solicitudes recibidas y puede aprobarlas o rechazarlas |
| Gestores | Se encargan de importar los calendarios escolares y realizar tareas de gestión |
| Técnicos informáticos | Participan en el mantenimiento técnico de la aplicación |

## 1.5. Problema que pretende resolver

Synkra pretende resolver la ineficiencia del procedimiento actual de solicitud y gestión de los días moscosos del profesorado. Este proceso se realiza manualmente mediante formularios en papel, lo que puede generar dificultades de control y organización, además de aumentar la carga de trabajo del equipo directivo.

Asimismo, el procedimiento actual dificulta que el profesorado pueda conocer previamente la disponibilidad de los días y consultar de forma inmediata el estado de sus solicitudes.

## 1.6. Motivación para desarrollar esta aplicación

La gestión de los días moscosos mediante formularios en papel puede provocar pérdida o inaccesibilidad de solicitudes, falta de visibilidad sobre su estado y dificultades para organizar los días disponibles.

Por ello, consideramos importante desarrollar una herramienta específica que permita centralizar la información y mejorar la organización del proceso. También es necesario tener en cuenta las necesidades de todos los usuarios, ya que una aplicación que no se adapte a ellas podría resultar difícil de utilizar y no ser aceptada por sus destinatarios.
