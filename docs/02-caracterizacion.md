# 2. Caracterización del reto

## 2.1. Descripción de la situación actual

Actualmente, la solicitud de días moscosos del profesorado se realiza mediante formularios en papel. El profesorado debe cumplimentar el formulario y entregarlo para que el equipo directivo pueda revisar la petición y decidir si se aprueba o se deniega.

Este procedimiento requiere una gestión manual de las solicitudes y dificulta que los usuarios puedan consultar de manera centralizada la información relacionada con los días moscosos.

## 2.2. Problemas o necesidades detectadas

A partir del análisis del procedimiento actual, se han identificado las siguientes necesidades:

- Evitar que las solicitudes puedan perderse o quedar inaccesibles.
- Permitir que el profesorado conozca qué días están disponibles antes de realizar una solicitud.
- Facilitar la consulta del estado de las solicitudes.
- Permitir conocer cuántos días moscosos le quedan por disfrutar a cada profesor.
- Reducir el trabajo manual que debe realizar el equipo directivo.
- Mejorar la organización y el control de las solicitudes recibidas.

## 2.3. Cómo se resuelve actualmente el problema

Actualmente, el procedimiento se realiza mediante formularios en papel.

El profesorado presenta una solicitud y el equipo directivo se encarga de revisarla y aprobarla o denegarla manualmente. La gestión y organización de las solicitudes también se realiza de forma manual.

## 2.4. Qué dificultades presenta el procedimiento actual

La falta de una herramienta centralizada genera dificultades operativas y de experiencia de usuario, tales como:

- Pérdida o inaccesibilidad de solicitudes.
- Falta de control y visibilidad sobre las solicitudes.
- Dificultad en la planificación de los días.
- Incertidumbre administrativa sobre el estado de las solicitudes.
- Mayor carga de trabajo para el equipo directivo.

## 2.5. Mejoras que aportaría la aplicación

La aplicación propuesta permitiría introducir las siguientes mejoras:

- **Agilidad y eficiencia:** facilitar la realización y gestión de las solicitudes.
- **Control y transparencia:** permitir consultar la disponibilidad y el estado de las solicitudes.
- **Mejora organizativa:** facilitar al equipo directivo la revisión y organización de las peticiones.
- **Centralización:** reunir la información relacionada con los días moscosos en un único sistema.
- **Notificaciones:** estudiar la posibilidad de incorporar avisos por correo electrónico o al móvil cuando cambie el estado de una solicitud.
